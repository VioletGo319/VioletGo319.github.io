# 同游 · 升官图（GitHub Pages）

游戏页面位于 ../shengguan/。完整保留 125 格棋盘、私密委托、六种锦囊、朝局预判、送礼、随机事件、朝堂争辩、同屏双人和单人人机对弈。
网页通过 https://game.xinyuwang.net/api/room 连接原站的双人雅间，无需 GPT 账号。
GitHub Pages 本身不提供联机数据库。若该服务在你的网络不可达，远程模式不能使用；同屏与单人模式仍可游玩。
页面首次成功加载并完成资源缓存后，可离线继续同屏或单人对局。远程对局始终需要网络。

## 重建

使用 Node.js 22.13 或以上版本，在本目录运行：

    npm install
    npm run build

将更新后的 ../shengguan/ 提交到 main 即可由已有的 GitHub Pages 发布。
保留仓库根目录 CNAME；不要修改游戏子目录中的相对资源路径。
更换联机服务时，修改 github-web/main.tsx 的 apiEndpoint，并在服务端配置准确的网页来源白名单。

## 手机桌面

iPhone：Safari → 分享 → 添加到主屏幕。
Android：浏览器菜单 → 安装应用 / 添加到主屏幕。
单人和同屏存档仅留在当前网站、当前浏览器，不能用联机密钥转移。
先添加桌面，再开局。远程棋局换浏览器或网站入口，使用原站“保存我的续局密钥”恢复自己的席位。

## 改编范围

规则资料见游戏内“玩法”。送礼人情、事件数值和争辩机制为游戏改编；不是古图原版的逐字复刻。
